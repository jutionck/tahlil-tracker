# Roadmap

Roadmap ini membantu kontributor memahami arah pengembangan **Tahlil & Yasinan Tracker**.

## Visi Project

Menjadi PWA open-source yang ringan, mudah digunakan, dan dapat berjalan offline untuk membantu keluarga serta komunitas di Indonesia dalam menghitung jadwal peringatan, membaca panduan digital, dan menyimpan pengingat sederhana tanpa bergantung pada backend.

## Phase 1 - Stabilitas Dasar

- [x] Kalkulator jadwal peringatan keluarga.
- [x] Dukungan kalender dan pasaran Jawa.
- [x] Konten bacaan digital.
- [x] Panduan perawatan dan tata cara terkait kebutuhan keluarga.
- [x] Dukungan PWA dan offline mode.
- [ ] Validasi ulang seluruh perhitungan tanggal dengan contoh kasus nyata.
- [ ] Tambahkan test case untuk utilitas tanggal.
- [ ] Perbaiki typo dan konsistensi bahasa pada konten.

## Phase 2 - Dokumentasi dan OSS Readiness

- [x] Tambahkan lisensi open-source.
- [x] Tambahkan panduan kontribusi.
- [x] Tambahkan security policy.
- [x] Tambahkan code of conduct.
- [ ] Tambahkan screenshot terbaru di README.
- [ ] Tambahkan demo link.
- [ ] Tambahkan panduan validasi konten.
- [ ] Tambahkan issue template dan pull request template.

## Phase 3 - UX dan Aksesibilitas

- [ ] Mode font besar.
- [ ] Mode kontras tinggi.
- [ ] Navigasi yang lebih ramah mobile.
- [ ] Perbaikan layout untuk layar kecil.
- [ ] Dukungan preferensi ukuran teks yang tersimpan.
- [ ] Audit aksesibilitas dasar.

## Phase 4 - Reminder dan Data Lokal

- [ ] Simpan beberapa profil keluarga di local storage.
- [ ] Pengingat jadwal yang lebih jelas.
- [ ] Export/import data secara lokal.
- [ ] Perbaikan pengalaman notifikasi PWA.

## Phase 5 - Kualitas dan Kepercayaan Konten

- [ ] Sertakan referensi atau sumber untuk konten utama.
- [ ] Tambahkan catatan bahwa praktik dan kebiasaan dapat berbeda antar daerah.
- [ ] Review konten oleh pihak yang kompeten.
- [ ] Tambahkan halaman disclaimer konten.

## Ide Lanjutan

- Dukungan bahasa daerah atau istilah lokal.
- Tema gelap.
- Audio bacaan.
- Mode cetak jadwal.
- Kalender bulanan untuk agenda keluarga.

## Catatan

Roadmap ini dapat berubah sesuai kebutuhan pengguna dan masukan kontributor.
